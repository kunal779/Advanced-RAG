\# Advanced RAG System



A hands-on project to understand and build an Advanced Retrieval-Augmented Generation (RAG) system from scratch.



\## 🎯 Goal



The goal of this project is to understand how modern RAG systems work internally, starting from a basic RAG pipeline and gradually improving it with advanced retrieval and agentic techniques.



\## 🧠 Learning Roadmap



\- \[ ] Basic RAG

\- \[ ] Document ingestion

\- \[ ] Text chunking

\- \[ ] Embeddings

\- \[ ] Vector search

\- \[ ] Hybrid search

\- \[ ] Query rewriting

\- \[ ] Multi-query retrieval

\- \[ ] Reranking

\- \[ ] Context compression

\- \[ ] RAG evaluation

\- \[ ] Self-RAG

\- \[ ] Agentic RAG

\- \[ ] Production-ready RAG
